# 2026 Remaining (IST)

A visual countdown showing the remaining time in 2026 with an interactive pixel grid display.

![2026 Remaining](https://img.shields.io/badge/Year-2026-00ff41?style=flat-square)
![IST Timezone](https://img.shields.io/badge/Timezone-IST-blue?style=flat-square)

## Features

- **365 Pixel Grid** - Each day of 2026 represented as a pixel forming "2026"
- **Real-time Updates** - Hours and percentage remaining update every second
- **Fire Emoji** - Current day highlighted with animated fire 🔥
- **Responsive Design** - Works on desktop and mobile
- **CRT Aesthetic** - Retro terminal green with scanline effects

## Tech Stack

- HTML5
- CSS3 (Custom properties, animations)
- Vanilla JavaScript (No dependencies)

## Usage

Simply open `index.html` in any modern browser. No build step required.
